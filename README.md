# 안국동 무료 한옥 길잡이 (Anguk Hanok Guide)

안국동과 북촌 일대의 **무료 방문 및 체험이 가능한 대표 한옥 4곳**(북촌한옥청, 계동배렴가옥, 북촌 한옥마을, 갤러리한옥)을 지도에서 한눈에 확인하고 탐방할 수 있는 웹 애플리케이션입니다.

## 🌟 주요 기능
1. **지도 위 빨간색 한옥 커스텀 마커**: 단청 붉은색 기와지붕 실루엣의 커스텀 SVG 마커 표시
2. **한옥별 상세 정보**: 마커 클릭 시 특징, 관람 시간, 문의처, 팁 및 원클릭 주소 복사
3. **길찾기 연동**: 네이버 지도, 카카오 맵, 구글 지도 3종 바로가기 제공
4. **가는 길 소소한 재밋거리**: 골목길 사이사이에 숨겨진 풍경과 즐길 거리 안내
5. **방문자 경험담 커뮤니티**: 다녀온 후기 및 나만의 꿀팁 등록 (`localStorage` 기반 보관) 및 공감(❤️) 기능
6. **추천 도보 순환 코스**: 안국역 3번 출구 기점 약 1.8km(도보 30분) 추천 산책로 지도 표시

## 🛠️ 기술 스택
- HTML5, Vanilla CSS3, Vanilla JavaScript
- Leaflet.js (OpenStreetMap / CartoDB)
